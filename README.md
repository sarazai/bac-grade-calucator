# Moroccan Baccalaureate GPA Calculator

A responsive, multi-language web application built with React and Tailwind CSS designed to help Moroccan high school students compute Baccalaureate GPAs and plan target exam scores.

## Features
- Multi-language UI support (Arabic, English, French)
- Automatic coefficient calculations for Moroccan Baccalaureate streams
- Score simulation for regional and national exams
